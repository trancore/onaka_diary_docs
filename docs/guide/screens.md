# 画面構成

画面下部のナビゲーションから、主に3つの画面を切り替えます。

![おなか日記の画面構成イメージ](/images/screen-map.svg)

これは操作の流れを示すイメージ図です。実際の画面は端末やテーマカラーによって見え方が異なります。

| アイコン | 画面 | できること |
| --- | --- | --- |
| ホーム | カレンダー | 日付ごとの記録を確認する |
| 人型アイコン | 登録 | 新しい日記を登録する |
| 歯車 | 設定 | 通知やテーマカラーを変更する |

## カレンダー画面

最初に表示される画面です。日付を選ぶと、その日の記録を確認できます。同じ日に複数の記録がある場合も、同じ日付から一覧で確認できます。

## 登録画面

食事、排便、腹痛の情報を入力して日記を登録します。日付は必須ですが、食事や排便時間などは分かる範囲で入力できます。

## 設定画面

記録リマインダーの有効・無効、通知時間、テーマカラーを変更できます。
