# 日記を登録する

## 1. 登録画面を開く

画面下部の人型アイコンをタップします。カレンダーで日付を選んでから登録画面を開いた場合は、その日付が入力候補になります。

## 2. 記録を入力する

| 項目 | 入力内容 | 補足 |
| --- | --- | --- |
| 日付 | 記録する日 | 必須 |
| 朝ごはん | 朝に食べたもの | 100文字まで |
| 昼ごはん | 昼に食べたもの | 100文字まで |
| 夜ごはん | 夜に食べたもの | 100文字まで |
| 排便時間 | 排便した時刻 | 分かる場合に入力 |
| うんこの状態 | なし・やわらかめ・ふつう・かため | 選択式 |
| 腹痛レベル | 痛みの強さ | 0〜10の11段階 |

腹痛レベルは、0が「全く痛くない」、10が「とても痛い」です。迷った場合は、その日の体感に近い値を選んでください。

## 3. 登録する

入力が終わったら「登録」をタップします。登録が完了するとカレンダー画面に戻ります。

日付が未入力の場合や、食事の入力が100文字を超えている場合は登録できません。画面に表示された案内に従って修正してください。
