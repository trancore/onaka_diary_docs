# よくある質問

## 入力を省略しても登録できますか？

日付以外の項目は、分かる範囲で入力できます。食事、排便時間、うんこの状態、腹痛レベルは必要に応じて記録してください。

## 同じ日に複数回登録できますか？

できます。同じ日付に複数の記録を保存でき、カレンダーから一覧で確認できます。

## 記録を削除したあとに復元できますか？

できません。必要な記録を削除しないよう、削除前に内容を確認してください。

## 通知時間だけ変更できますか？

できます。設定画面の「通知時間」から時刻を変更してください。記録データには影響しません。

## データはどこに保存されますか？

日記データは端末内に保存されます。端末の変更やアプリの削除によるデータの扱いは、利用している端末のバックアップ設定を確認してください。
